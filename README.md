# AI-Powered Resume Screening & Job Recommendation System

An AI-powered system designed to assist with resume screening and job recommendation using Natural Language Processing (NLP), semantic matching, candidate-job ranking, explainable results, and fairness evaluation.

## Project Overview

This project aims to develop an intelligent system that can process resumes, extract relevant information, compare candidate profiles with job descriptions, rank candidates based on compatibility, and recommend suitable job opportunities.

## Objectives

- Resume document processing
- Resume information and skill extraction
- Job description processing
- Candidate-job matching
- Compatibility scoring
- Candidate ranking
- Job recommendation
- Explainable matching results
- Fairness evaluation

## Technology Stack

- Python
- Flask
- HTML
- CSS
- JavaScript
- Natural Language Processing (NLP)
- Scikit-learn
- Sentence Transformers
- PDF/DOCX text extraction

## System Workflow

Resume Upload
→ Document Processing
→ Text Extraction
→ NLP Preprocessing
→ Information & Skill Extraction
→ Job Description Processing
→ Candidate-Job Matching
→ Ranking & Recommendation
→ Explanation
→ Evaluation
